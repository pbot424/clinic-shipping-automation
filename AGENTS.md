# Public portfolio edition

This repository contains a fictional demo and sanitized shipping automation source.

- Keep the default launch path simulated. Never run real FedEx or printer operations during tests.
- Use fictional recipients, reserved example.test emails, and demo sender IDs in committed files.
- Do not commit local directories, manifests, shipment history, tracking exports, credentials, employer branding, or operational screenshots.
- Preserve serial submission, durable claims, uncertain-result blocking, and separate tracking collection.
- Keep the README focused on the product, its purpose, and the user workflow. Put installation and operational detail in docs/.
- Run the relevant unittest modules. On Windows, also run the isolated PowerShell startup test when changing startup behavior.
